# Участие в разработке

Спасибо, что хотите помочь! Ниже — как устроен проект и как внести изменения.

## Устройство

- `src/` — исходники по модулям. Они склеиваются **по порядку имён** в один `nl_helper.js` (это обычный скрипт внутри одной IIFE, без import/export — функции и константы из разных модулей видят друг друга).
- `nl_helper.js` — готовый файл для Tampermonkey и Greasy Fork. **Не правьте его руками** — правьте `src/` и запускайте сборку. CI проверяет, что файл совпадает со сборкой.
- `tests/test.js` — тесты логики (Node.js, без браузера и зависимостей); `tests/fixtures/` — данные для тестов; `tests/stand/` — локальная имитация страницы темы.

| Модуль | Что внутри |
|---|---|
| `00-meta.js` | заголовок userscript (`@version`, `@match`, права) |
| `01-core.js` | версия, дата редакции правил, ключи хранилища, селекторы форума |
| `02-config.js` | префиксы, вкладки, темы, MG-термины, требования к биографии, оформление поста |
| `03-templates.js` | шаблоны ответов по разделам |
| `04-rules-general.js` | таблица «Общих правил серверов» |
| `05-rules-orgs.js` | правила гос./крим. организаций и лидеров, сборка `RULES`, текст поста по пунктам |
| `06-defaults.js` | теги и генерация шаблонов по пунктам правил |
| `07-storage.js` | загрузка/сохранение, миграция, экспорт/импорт |
| `08-page.js` | разбор страницы: автор, тема, текст поста |
| `09-dialogs.js` | диалоги и доступность, шрифты, проверка обновлений правил |
| `10-insert.js` | вставка в редактор, предпросмотр, префиксы, анти-флуд, статистика, хоткеи |
| `11-styles.js` | CSS |
| `12-main-window.js` … `18-settings.js` | окна: главное, конструктор, мастер, командная строка, панели, биографии, настройки |
| `19-init.js` | уведомления, кнопки на форуме, запуск |

## Порядок работы

```bash
npm test        # перед изменениями — убедиться, что всё зелёное
# …правки в src/…
npm run build   # собрать nl_helper.js
npm test
npm run stand   # проверить в браузере: http://127.0.0.1:8765/threads/test.12345/
```

Нужен только Node.js 18+; `npm install` не требуется.

## Правила

- Пишите комментарии и тексты интерфейса по-русски, как в остальном коде.
- Всё, что попадает в HTML, экранируйте через `esc()`; ссылки в BB-код — только через `safeUrl()`.
- Никаких внешних запросов, кроме самого форума и Google Fonts; новые `@grant` — только по веской причине и с описанием в SECURITY.md.
- Не меняйте id существующих шаблонов и порядок основных пунктов в `RULE_TABLE` — к ним привязана статистика кураторов (подробнее в [docs/UPDATING-RULES.md](./docs/UPDATING-RULES.md)).
- Новая функция — строка в `CHANGELOG.md` и, если нужно, тест в `tests/test.js`.

## Как сообщить о проблеме

Создайте [Issue](https://github.com/nuratropic/nl-helper/issues): что делали, что ожидали, что получилось, браузер и версия скрипта (видна в окне помощника). Об уязвимостях — по [SECURITY.md](./SECURITY.md).

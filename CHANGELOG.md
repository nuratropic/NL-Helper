# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [Semantic Versioning](https://semver.org/lang/ru/).

## [6.5.0] — 2026-11-25

### Добавлено
- **Стиль поста «Detroit»** («чертоги разума» из Detroit: Become Human) — теперь по умолчанию: шапка «Ответ на обращение», баннер статуса по префиксу ответа (одобрено, отказано, на рассмотрении, решено, закрыто), текст в цитате, пункты правил в виде «■ 2.04 НАЗВАНИЕ · описание · мера», плашка «Задача выполнена». Прежнее оформление — «Классика» в настройках.
- Баннеры и их генератор — в `docs/design/` (`generate-dbh2.html`).
- Предпросмотр показывает цитаты и настоящий шрифт поста.

## [6.4.1] — 2026-11-23

### Добавлено
- Работа на iPhone через Userscripts (Safari): если менеджер не даёт `GM_getValue/GM_setValue`, данные хранятся в localStorage форума.
- Вид для телефона: окно на весь экран, крупные кнопки, диалоги в одну колонку.
- Пошаговая инструкция установки для компьютера, Android и iPhone — [docs/INSTALL.md](./docs/INSTALL.md).

## [6.4.0] — 2026-11-23

### Добавлено
- **Слежение за правилами.** Раз в 12 часов скрипт смотрит даты последних сообщений в темах с правилами (общие, лидеры, гос./крим. организации, биографии, ситуации, неоф. организации, правила подачи жалоб) и показывает уведомление, если правила изменились после редакции, с которой сверены шаблоны. Проверка вручную — в настройках, по команде «правила» (`Alt`+`K`) и в меню Tampermonkey.
- **Правила организаций и лидеров**: «Общие правила для государственных организаций» (редакция 14.11.2026), «Общие правила криминальных организаций» (03.04.2026), «Правила и обязанности лидера» (14.11.2026) — в конструкторе, мастере и командной строке («гос 1.07», «крим 4», «лид 3.21»).
- **Раздел форума определяется автоматически** по «хлебным крошкам»: окно открывается на нужной вкладке, мастер пропускает выбор категории, «Разобрать» в разделе биографий открывает анализатор.
- **Сервер для `{server}`** берётся из раздела форума («Сервер №91 | ASTANA» → ASTANA).
- **Срок рассмотрения**: сколько тема ждёт ответа и сколько осталось (2 рабочих дня для жалоб, 72 часа для обжалований, биографий, ситуаций и заявок).
- **Проверка формы подачи** в мастере с кнопкой отказа «не по форме»; новые шаблоны `l6` (жалоба на лидера) и `ap9` (обжалование) не по форме.
- **Плейсхолдеры** `{violator}` (ник нарушителя из формы) и `{curator}` (ваш ник).
- **Предпросмотр поста** перед вставкой (режим в настройках) и кнопка 👁 в редакторе шаблона.
- **Настройка оформления поста**: картинки шапки и подвала, обращение, строка перед сервером, подпись.
- **Доступность**: окна помечены как диалоги, фокус переходит внутрь и не уходит за окно по `Tab`, возвращается после закрытия; карточки шаблонов открываются с клавиатуры; у кнопок-иконок есть подписи; видимая рамка фокуса.
- `@updateURL` / `@downloadURL` (Greasy Fork), `@homepageURL`, `@supportURL`.
- Исходники разбиты на модули в `src/` со сборкой `tools/build.js`, тесты в `tests/`, локальный стенд, CI на GitHub Actions.

### Изменено
- Шрифты Google Fonts загружаются только при первом открытии окна, а не на каждой странице форума.
- При равной похожести общие правила в подборе выше правил организаций.

### Исправлено
- Конструктор нарушений не открывался кнопкой в окне после добавления фильтра по наборам правил.

## [6.3.0] — 2026-11-23

### Изменено
- Таблица «Общих правил серверов» сверена с редакцией от 14.11.2026: обновлены 2.01, 2.04 (теперь «существенные помехи», Ban 3 дня), 2.19, 2.48, 3.12, 4.05; исправлены наказания 2.21, 2.32, 2.40, 4.15.
- Добавлены примечания с отдельным наказанием: 2.02 (уход от ареста), 2.19 (DM/таран игроков на системной работе), 2.32 (услуги обзвона).
- Новые шаблоны по правилам подачи жалоб и обжалований, шаблоны биографий/ситуаций/организаций — с 24 часами на доработку.
- Анализатор биографий проверяет 200–600 слов, разделы формы подачи, заголовок, читает текст в спойлерах и предлагает шаблон.
- Хранилище шаблонов: только правки пользователя (~130 КБ → меньше 1 КБ); данные 6.2 переносятся автоматически.

### Исправлено
- Обновлённые тексты правил не доходили до тех, у кого скрипт уже был установлен.
- Префикс ставился по неверному адресу на 2-й и следующих страницах темы.
- Автор темы и первый пост брались из первого попавшегося элемента страницы.
- Текст вставлялся в редактор без экранирования; повреждённые данные хранилища ломали запуск.
- Горячие клавиши конфликтовали с AltGr; статистика по дням велась в UTC.

# Как установить NL Helper — пошагово

Выберите своё устройство и делайте **строго по шагам**. Ничего не пропускайте.

Файл скрипта в архиве: **`nl_helper.user.js`**.
Ссылка для установки: **https://greasyfork.org/ru/scripts/582289-nl-helper**

---

## 💻 КОМПЬЮТЕР (Chrome, Яндекс Браузер, Edge, Opera, Firefox)

**Шаг 1. Поставьте расширение Tampermonkey**
- Chrome / Яндекс / Opera: https://chromewebstore.google.com/detail/dhdgffkkebhmkfjojejmpbldmpobiwkp → «Установить».
- Edge: https://microsoftedge.microsoft.com/addons/detail/iikmkjmpaadaobahmlepeloendndfphd → «Получить».
- Firefox: https://addons.mozilla.org/ru/firefox/addon/tampermonkey/ → «Добавить в Firefox».

**Шаг 2. Только для Chrome, Яндекса, Edge, Opera — разрешите скрипты** (без этого НЕ заработает!)
1. В адресной строке откройте `chrome://extensions` (в Edge — `edge://extensions`).
2. У Tampermonkey нажмите **«Подробнее»**.
3. Включите переключатель **«Разрешить пользовательские скрипты»** (Allow User Scripts).
   Если такого переключателя нет — включите **«Режим разработчика»** в правом верхнем углу страницы расширений.

**Шаг 3. Установите скрипт**
- **Способ А (проще):** откройте ссылку Greasy Fork выше → зелёная кнопка **«Установить этот скрипт»** → в окне Tampermonkey **«Установить»**.
- **Способ Б (из архива):** распакуйте архив → нажмите на значок Tampermonkey → **«Создать новый скрипт»** → удалите всё, что там написано → откройте `nl_helper.user.js` Блокнотом, выделите всё (`Ctrl+A`), скопируйте (`Ctrl+C`), вставьте в Tampermonkey (`Ctrl+V`) → **`Ctrl+S`**.

**Шаг 4. Проверьте:** откройте любую тему на forum.blackrussia.online → обновите страницу (`F5`) → рядом с кнопкой «Ответить» появится **⬡ NL HELPER**.

## 🤖 ANDROID (телефон)

На Android работает **только через браузер Firefox** (в Chrome для телефона расширений нет).

1. Установите **Firefox** из Play Маркета.
2. В Firefox откройте https://addons.mozilla.org/ru/android/addon/tampermonkey/ → **«Добавить в Firefox»** → **«Добавить»**.
3. В Firefox откройте ссылку Greasy Fork выше → **«Установить этот скрипт»** → **«Установить»**.
4. Откройте тему на форуме **в Firefox** → потяните страницу вниз, чтобы обновить → появятся кнопки NL Helper.

На телефоне окно помощника открывается на весь экран. Горячие клавиши на телефоне не нужны — всё делается кнопками.

## 🍏 iPhone / iPad

Работает **только в Safari**, через бесплатное приложение **Userscripts** (нужен iOS 15 или новее).

**Шаг 1.** Установите из App Store приложение **Userscripts** (разработчик Justin Wasack): https://apps.apple.com/app/userscripts/id1463298887

**Шаг 2.** Откройте приложение Userscripts → нажмите **«Set Userscripts Directory»** (выбрать папку) → выберите папку, например «На iPhone» → создайте папку **Userscripts** → **«Открыть»**.

**Шаг 3. Включите расширение:** Настройки iPhone → **Приложения → Safari → Расширения** → **Userscripts** → включите → «Разрешения для сайтов» → **«Все веб-сайты» → «Разрешить»**.
(На старых iOS путь: Настройки → Safari → Расширения.)

**Шаг 4. Положите скрипт в папку:**
1. Скачайте архив на iPhone и откройте его в приложении **«Файлы»** — он распакуется сам (нажмите на архив).
2. Нажмите и подержите файл **`nl_helper.user.js`** → **«Переместить»** → выберите папку **Userscripts** из шага 2.

**Шаг 5.** Откройте тему на форуме в **Safari** → нажмите **«aA»** (или значок пазла) в адресной строке → **Userscripts** → убедитесь, что скрипт **NL Helper** включён → обновите страницу.

## ❓ Не работает — проверьте по порядку

1. **Вы внутри темы?** Кнопки есть только в темах (адрес содержит `/threads/`), а не в списке тем.
2. **Обновили страницу** после установки?
3. **Компьютер:** включён ли переключатель «Разрешить пользовательские скрипты» (шаг 2)? Это причина №1.
4. **Скрипт включён?** Значок Tampermonkey → «Панель управления» → у NL Helper переключатель должен быть зелёным.
5. **Две копии скрипта?** Удалите лишнюю в «Панели управления».
6. **Android:** открываете форум именно в **Firefox**?
7. **iPhone:** открываете в **Safari** (не в Chrome), расширение Userscripts разрешено для всех сайтов, файл лежит в той самой папке?
8. Кнопка «Ответить» не видна (тема закрыта / вы не вошли) — кнопки NL Helper будут **внизу справа**.
